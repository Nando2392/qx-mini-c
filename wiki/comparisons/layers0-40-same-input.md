# Layers 0–40 exact same-input classification

> Estado: **GREEN local para 41/41 capas**. Issue: [#16](https://github.com/Nando2392/qx-mini-c/issues/16).
> Este resultado no demuestra paridad acumulada ni exactitud global.

## Pregunta y contrato

Después del fix de [[layer41-iq3s-q8k]], el bisect descendente regeneró cada capa de 40 a 0 con token `42`, oracle llama.cpp `768d2a481a99cb75ec9a03b95dadbd35e7acf496`, `q8_k_compat` y KV F16. Para cada layer `N`:

1. el oracle escribió `layer-N.f32` y 19 internals;
2. QX attention recibió ese residual exacto;
3. QX MoE recibió el `ffn_inp-N.f32` producido por esa atención;
4. el comparador exigió `Vcur=512` y `kqv_out=4096`;
5. routing, role-specific kernels, checkpoints y reconstrucción se evaluaron separadamente.

Los sidecars y reportes viven sólo en `%LOCALAPPDATA%\Temp`; la prueba pytest regenerable versiona la provenance sin guardar `.f32` ni JSON experimental.

## Resultado

- `41/41` capas materialmente cerradas; no apareció un nuevo bug de runtime.
- Routing top-8 exacto en las 41 capas.
- Máximo `Vcur`: `1.7881393432617188e-7` (layer 38).
- Máximo `kqv_out`: `1.9073486328125e-6` (layer 1).
- Máximo `ffn_inp`: `3.814697265625e-6` (layer 4).
- Máximo weighted: `1.8310546875e-4` (layer 2).

- 37 capas exceden únicamente el umbral diagnóstico estricto de router logits `2e-6`; routing, pesos normalizados, weighted y reconstrucción permanecen cerrados.

Cada celda numérica usa `max_abs / RMSE / cosine`.

## Veredicto y límite

No existe una nueva frontera local antes de layer 41 para este modelo/input: todas las capas 0–40 cierran cuando reciben el mismo residual. Junto con los gates publicados de layers 41–44, layer 46 y layer 47, esto refuta la hipótesis de un segundo seam local material pendiente en el intervalo probado. No autoriza afirmar bit-parity global: el forward normal alimenta cada bloque con un residual QX ya perturbado y esas diferencias pequeñas pueden acumularse o amplificarse.

Siguiente trabajo causal: medir acumulación adyacente sobre el forward real con replay híbrido/bisect de inyección, no implementar otro kernel por analogía. F32 sigue default; `q8_k_compat` sigue CPU-only y opt-in.
